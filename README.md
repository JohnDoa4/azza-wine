# Wine AZZA — HTML-верстка, версия 1

Кликабельный прототип приложения: все экраны из секции **Final** в Figma (страница `WIne 2026`), переходы, карусель карточек, подбор вина по формуле из книги (65 % еда, 20 % повод, 15 % популярность), каталог с поиском и фильтрами.

## Как открыть

- Двойным кликом по `index.html` (работает из папки, без сборки). Шрифты Geologica и Playfair Display подгружаются с Google Fonts — без интернета будут запасные.
- Либо локальным сервером без кеша: `python tools/serve.py 8792` → http://127.0.0.1:8792/index.html
- На компьютере приложение показывается в рамке телефона 375×812 слева — панель разработчика (переход на любой экран, переключатели геолокации, сети и карты). На экране до 520 px приложение занимает весь экран, панель скрыта.
- Адрес вида `index.html#/results` открывает нужный экран напрямую (`#/wine?id=ponte-merlot`, `#/catalog?sheet=filters`, `#/map?store=ganjlik&sheet=nav`).

## Карусель

Центральная карточка стоит ровно, соседние повёрнуты на 15° (слева против часовой стрелки, справа по часовой — как в Figma: слева `+15°`, справа `−15°`; в CSS это `rotate(-15deg)` и `rotate(15deg)`). Карточка 300×310 с эффектами из Figma (скругление 2rem, фон белый 70 %, внутренние линии, тень 0 12px 40px, размытие фона). Картинка занимает всю ширину карточки (300×300 со смещением 20 px), заголовок и подпись лежат в колонке (автолейаут), поэтому длинные названия переносятся и не накладываются на подпись или флаг. Положения считаются из ширины контейнера. Свайпы работают пальцем (`touch-action: pan-y`) и мышью.
Первая карточка на каждом шаге — нейтральная: «Без повода / Для себя», «Не важно / Без еды», «Не важно» (цвет), «Все страны», на главной — «Подобрать вино».
Управление: перетаскивание (одно движение — одна карточка), клик по соседней — сделать центральной, клик по центральной или «Продолжить» — выбор и дальше, стрелки на клавиатуре. Не зациклена (флаг `loop` не реализован).

## Карточка вина

Бутылка лежит во фрейме 200 px (отступ 12, по центру, растягивается по высоте), сама бутылка шириной 10,444 rem с пропорцией 25:86 занимает всю высоту фрейма и не заходит под нижнюю панель. Часть бутылки спрятана за правым краем. Свайпом влево бутылка плавно (без шагов, вслед за пальцем) выезжает в центр, описание уезжает за левый край, фон сдвигается вместе с ними (сдвиги из Figma: бутылка −172 px, описание −260 px, фон −278 px); отпускание «доводит» до ближайшего положения. Тап переключает положение.

## Анимации

Контент каждого экрана появляется по очереди сверху вниз: из прозрачности с небольшим сдвигом по вертикали (`.rise`, см. `reveal` в `js/router.js`).

## Отличия от макета и допущения

- **Назад** ведёт на предыдущий шаг (в Figma стрелка на шагах 3–5 ведёт на главную). «Список вин» в карточке возвращает туда, откуда пришли.
- **Кнопка на главной** называется по выбранной карточке («Подобрать вино» / «Открыть каталог»), в Figma — «Продолжить».
- **Мало вариантов:** вина из других стран показываются в том же списке отдельным блоком с пояснением (как в последнем макете), страна не подменяется молча.
- **Карточки каруселей** без бейджей и подсказок. Рекомендации («Рекомендует сомелье», «Отличный выбор», «Хороший выбор») показываются только в списке результатов и на странице вина.
- **Бейджи в результатах** по месту в рейтинге: 1 — «Рекомендует сомелье», 2 — «Отличный выбор», 3 — «Хороший выбор» (при совместимости ≥ 4/≥ 4/≥ 3).
- **«Красное мясо»** = стейк, баранина, BBQ (свинина в карточку не входит).
- **Профиль вина** на карточке (тело, кислотность, танины, ароматность) — экспертная оценка из книги, не лабораторные данные; химию сладости («Сухое/не указано») как факт не показываем.
- **Язык:** переключатель работает только как выбор; интерфейс остаётся русским (показывается подсказка). Перевода на AZ/EN нет.
- **Магазины:** три заглушки (адреса, часы и расстояния вымышлены). **Карта** — картинка `assets/images/map-sample.png`; метки магазинов кликабельны, внизу всегда одна карточка выбранного магазина и она меняется по клику на метку.
- **Бюджет:** диапазон двумя ползунками; 12 столбиков гистограммы показывают условное распределение цен; по умолчанию 10–40 ₼.
- **Данные:** 10 вин из книги (`tools/data/wines_engine.csv`), в т. ч. Ponte Merlot, Carpineto Dogajolo (красное и белое), Camillo Pietraja, Paul Mas (3), Durujuli Saperavi, Santa Julia, Ponte Spumante. Вместо Camillo Passerina взято Dogajolo Bianco: в книге у Passerina цвет «Красное» при белом профиле (ошибка данных, нужна проверка).
- Заголовки экранов «Personal sommelier» и «Wine Card» оставлены как в Figma (англоязычные).

## Как пересобрать

```
python tools/build_assets.py        # копия картинок с латинскими именами + оптимизация фото 10 вин
python tools/build_data.py          # js/data.generated.js (10 вин); --all — все 380 (фото нужны отдельно)
node tools/test_engine.js           # проверка движка на сценарии «Ужин / красное мясо / красное / Италия / 10–40 ₼»
```
